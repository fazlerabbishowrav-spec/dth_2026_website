# Which open source project would be useful in your major, and why?

## Which open source project would be useful in your major, and why?


Zotero and European Studies

Zotero is an open-source tool for collecting and organising academic sources. It helps users save articles, manage references and create citations. The project was created at George Mason University and is now developed by Digital Scholar with support from a wider community.

How can it help my major?

European Studies includes topics such as migration, EU policies, human rights and international relations. Students often work with many academic articles and reports, which can be difficult to organise.

Zotero can make this work easier. During my thesis research on migrant labour market integration in Denmark and Sweden, I can use folders for different topics, save useful articles and add notes. It also helps create citations and reference lists, which saves time during academic writing.

Checking the project

- Licence: Zotero uses the GNU Affero General Public License version 3 (AGPL-3.0). Users can study, modify and share the software under its licence conditions.

- Last change: GitHub shows the project's development activity and recent commits. This helps users check whether the software is still maintained.

- People: Zotero has developers and community contributors. Their work can be seen in the GitHub repository.

- Questions: Users can ask for help through Zotero's official support forum. GitHub is mainly used for development discussions and technical issues.

- Money: Zotero receives income from individual and institutional storage subscriptions. This helps cover development and operating costs.

My opinion

I would use Zotero for my thesis because it makes academic research easier to organise. It also helps me manage references and avoid mistakes in citations. I would still keep backup copies of important documents.

If the original developers stopped working on Zotero, other developers could continue the project because its source code is available. However, its future would depend on people who are willing to maintain it.
